# Note visuals

No source note images were supplied. Hand Beat uses the standard hand emoji
✊ / 👉 / ✋ / 👏 and different square / diamond / circle / hexagon outlines.

The accessible HTML presentation is `src/components/NoteIcon.tsx`; the gameplay
Canvas renderer is `src/game/draw.ts`. Colors and labels are centralized in
`src/game/config.ts`. Asset replacement must preserve these four gestures.
